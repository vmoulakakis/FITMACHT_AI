# FitMatch UI / UX execution contract
Read central source through an authenticated GitHub connector or synced skills workspace:
- skills/web-design-intelligence/SKILL.md

Then read root DESIGN.md and AGENTS.md. This local minimum works only as a fallback when canonical sources cannot be retrieved. Record that limitation.

## Product-specific art direction
Trustworthy Greek decision aid, not an e-shop, catalog grid, or AI spectacle.
Use brand evergreen, lime/cream, existing DM Sans / Manrope, semantic labels and visible evidence. Reject fabricated stock, savings, ratings, specs and merchants.

## No-scroll workflow
- Desktop: one contained viewport with tabs, not scroll-triggered chapters.
- Mobile: same step navigator, touch-safe controls and persistent legal disclosures.
- Always permit **internal** scrolling when needed to avoid clipped content at 320px, 200% zoom, landscape and long Greek strings.
- React state + AJAX recommendation; loading/empty/error/retry/success focus transitions. Preserve answers on failure.
- More than three product candidates are not displayed; all visible outbound links pass existing eligibility and exact-host security guards.
- When inventory is zero: give an honest category explanation, measurement checklist, useful non-purchase next step.

## Three.js
Only optional on-demand scene, never on primary critical path, progressive CSS fallback for WebGL failure, reduced motion and underpowered phones. Dispose renderer/materials/RAF/observers. Do not pretend a schematic is actual product size.

## Mandatory evidence before releasing
CI tests, TS, build; independent smoke test of source and deployed anonymous status, 390/768/1440 layouts, keyboard focus, mobile overflow, 200% zoom, reduced motion, low-end runtime, live zero-inventory, and fully verified offer redirects. No production GREEN from a successful build alone.
